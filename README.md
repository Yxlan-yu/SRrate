# 刷新率（SRrate）

基于 Jetpack Compose + Miuix 重构的屏幕刷新率管理工具（原版作者：酷安 爱好者ahh；重构：叶昕蓝yu）。

## 主要功能
- 屏幕刷新率：查看并切换设备支持的刷新率档位，实时显示当前分辨率与帧率。
- 自动超频：守护线程按目标分辨率/帧率持续生效，覆盖系统限频。
- 自定义应用刷新率：按单个应用设置专属分辨率/帧率，与自动超频可同时开启。
- 远程刷新率：通过 ADB 无线/USB 控制被控设备的刷新率（需在被控端开启无线调试或 USB 调试）。
- 原生刷新率覆盖：使用系统原生命令切换（需 Root 或 Shizuku 授权）。

## v1.1 更新内容
1. **自定义页返回链修正**：从「启用名单 → 应用配置」进入配置页后，返回键现在正确回到「自定义」主页，不再误回错误的二级页。
2. **应用管理列表流畅度**：应用列表改用惰性渲染（仅生成可见项），长列表滑动不再因整屏构建而卡顿。
3. **其他机型分辨率识别**：挡位列表优先采用系统 API 读取真正支持的显示模式（免 Root），失败时回退 dumpsys，最终兜底使用当前真实分辨率派生，不再硬编码型号分辨率，其他机型也能正确识别与切换。
4. **Android 17 / 16KB 页大小兼容**：
   - 移除「可调试应用」的安装警告（改用正式签名构建）。
   - 升级/对齐存在 16KB 页大小风险的依赖（graphics-path 1.0.1、conscrypt 2.6.3），保证在 16KB 页大小设备上能正常安装并运行。

## 已知限制
- **无线配对（spake2 库）未做 16KB 页大小对齐**：在采用 16KB 页大小的系统上，无线 ADB 配对可能不可用（App 内已给出提示）。USB 远程控制不受影响；root/Shizuku 方式管理刷新率不受影响。

## 构建
- 本仓库通过 GitHub Actions 构建（`gradle assembleRelease`，使用固定 keystore 签名，Release 可直接安装）。
- 本地构建：`gradle assembleRelease`，产物在 `app/build/outputs/apk/release/`。
