# 刷新率（SRrate）

基于 Jetpack Compose + Miuix 重构的**屏幕刷新率管理工具**（Miuix 版），帮助你在手机上一键查看、切换、守护想要的屏幕刷新率与分辨率。

原始思路：酷安 **爱好者ahh**（pmahz 屏幕刷新率）。

## 功能

- **屏幕刷新率**：查看设备支持的全部分辨率 / 刷新率档位，点击即可切换；实时显示当前分辨率与帧率（省电模式下自动提示）。
- **自动超频守护**：后台守护线程按目标分辨率 / 帧率持续生效，防止系统把刷新率悄悄降回去。
- **自定义应用刷新率**：为单个应用设置专属分辨率 / 帧率，打开该应用即自动切换，退出后回落；可与「自动超频」同时开启，未配置的应用保持全局目标。
- **远程刷新率**：通过 ADB（无线 / USB）调节被控端设备的刷新率，可管理多台设备与历史连接，适合连接电视、盒子、其它手机等副屏设备。
- **原生刷新率覆盖**：使用系统原生 `cmd display` 命令切换刷新率，并同步写入系统设置。
- **检查更新**：App 内手动检查 + 每日后台静默检查；发现新版本后弹窗内实时进度条下载，支持多源自动切换（GitHub 直连 / gh-proxy.com / gh-proxy.org），无需网络工具即可正常更新。

## 授权方式

- **Root / Shizuku / 无障碍**：三种授权任选，均支持本机刷新率切换。
- **远程控制**：被控端开启无线调试或 USB 调试即可。

## 系统要求

- Android 7.0 **及以上**（minSdk 24）。

## 安装

从 **Releases** 下载 APK 安装即可。签名固定，后续版本可直接覆盖安装（无需卸载）。

## 已知限制

- 无线配对（libspake2）在 16KB 页大小的设备上不可用，App 内有提示，可用 USB 连接代替；Root / Shizuku 切换刷新率不受影响。

## 构建

- 工程使用 GitHub Actions 构建：`gradle assembleRelease`，使用固定 keystore 签名；产物在 `app/build/outputs/apk/release/`。
