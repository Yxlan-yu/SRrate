# 刷新率（SRrate）

基于 Jetpack Compose + Miuix 构建的**屏幕刷新率管理工具**，帮助你在手机上查看、切换、守护想要的屏幕刷新率，并为单个应用单独配置专属档位。已发布 **v1.5.0（最终版）**，自此无限期停更。

## 功能

- **主页 · 刷新率档位**：查看设备支持的刷新率 / 分辨率档位，点击即可切换；顶部标题栏全透明，内容上滑时直接透出底层画面。
- **自动超频守护**：后台守护线程按目标刷新率持续生效，防止系统把刷新率悄悄降回去（Root / Shizuku 下稳定守护）。
- **工具 · 实时帧率**：实时渲染帧率检测，配合动图让帧率持续拉满，直观看到当前帧率变化。
- **自定义 · 应用专属刷新率**：开启「自动超频守护」后，可在应用管理中为单个应用单独配置专属分辨率 / 刷新率——打开该应用自动切换到专属档位，退出后回落到全局目标；未单独配置的应用保持全局守护档位。支持搜索、显示系统应用、逐应用停用。
- **原生刷新率覆盖**：使用系统原生 `cmd display` 命令切换刷新率，并同步写入系统设置。
- **检查更新**：启动时自动检查 + 手动检查；稳定版 / 测试版双更新通道，发现新版本后弹窗下载；支持多源切换（GitHub 直连 / gh-proxy.com / gh-proxy.org），无需网络工具即可正常更新。

## 界面

- **底部导航**：主页 / 自定义 / 工具 / 设置 四页，可左右滑动切换；「高级材质」开启后底栏变为居中悬浮的液态玻璃胶囊（需 Android 13 及以上）。
- **主题**：莫奈取色（跟随壁纸）、颜色选择（8 种预置色 / HSV 选色面板）、深色模式。
- **多语言**：跟随系统 / 简体中文 / English，切换立即生效无需重启。

## 授权方式

- **Root / Shizuku / 无障碍**：三种授权任选其一，即可本机刷新率切换与守护。
- **原生悬浮显示**：以悬浮窗形式展示当前刷新率。

## 系统要求

- Android 7.0 **及以上**（minSdk 24）。
- 「高级材质」玻璃胶囊需 Android 13（API 33）及以上。

## 安装

从 **Releases** 下载 APK 安装即可。签名固定，后续版本可直接覆盖安装（无需卸载）。

## 构建

- 工程使用 GitHub Actions 构建：`gradle assembleRelease`，使用固定 keystore 签名；产物在 `app/build/outputs/apk/release/`。
